# 玩偶图解工作台 · Amigurumi Studio

把「想要的形状」变成「能照着钩的图解」，并且**在钩之前先看见它**。

## 为什么做这个

钩针玩偶的底层是一套很硬的逻辑，三步就能写清楚：

```
第 n 圈针数：  cₙ = cₙ₋₁ + incₙ − decₙ
该圈周长：     Pₙ = cₙ · w          （w = 针宽）
该圈半径：     rₙ = cₙ · w / 2π
该圈高度：     hₙ = n · h          （h = 针高）
```

**加针率就是曲率**：每圈正好加 6 针（短针）走平面，加得少就往上鼓成球，加得多就往外张成马鞍。
所以「设计玩偶」= 设计一条**针数曲线**，图解只是把这条曲线记录下来。

但公式只在「计数与拓扑」这一层成立，有三件事必须承认：
1. `w`、`h` 取决于线材 + 钩针 + 手劲，是**参数**不是常数；
2. 塞棉量和线的弹性会影响最终形状；
3. 整数化 + 可钩性约束会修改序列，所以**成品必然偏离目标轮廓** —— 本项目把这个偏差量化出来给你看，而不是假装公式是精确的。

## 核心主张

> 图解不是唯一解，是一个**解族**。
> 所以我们不追求「生成标准答案」，只追求「**合法**且**拟合目标**」。

- **合法** = 每一圈消耗的针目数严格等于上一圈的针目数（耦合守恒）
- **拟合** = 针数曲线对应的轮廓尽量贴近你给的剖面

## 跑起来

```bash
node test/run.js          # 跑测试，45 项，无需安装任何依赖
node scripts/serve.js     # 本地预览，然后打开：
                          #   图解可视化   http://127.0.0.1:5173/web/chart.html
                          #   3D 形状预览   http://127.0.0.1:5173/web/
```

两个页面都是纯静态 ES 模块。3D 页唯一的第三方依赖 **three.js** 通过 importmap 从 CDN 加载（首次打开需联网）；
图解页零依赖。模块在 `file://` 下会被浏览器拒绝，所以必须走 HTTP —— 这就是 `scripts/serve.js` 存在的原因。

### 图解可视化窗口

- **每个符号画在它真正穿的那一针上**：`sc`/`inc` 画在消耗的那个针目的角度，`dec` 画在两针的中点。
  所以加针密集处会自己显现出来，不会被"平均分角度"抹平。
- 同心圆是圈引导线，从内到外是第 1 圈到最后一圈；正上方那一列是 **圈号·针数**（如 `4·24` = 第 4 圈共 24 针）。
- 加针画成 **V**（一针出两针，两个针目合成一个符号），减针画成 **A**（两针并一针）。
- 改剖面控制点，图解实时重画；右下角同步给出文字图解、校验结论与**整数化偏差**。
- 「打印」按钮走 print 样式表，只输出图解本体，可直接打印带钩。

### 3D 形状预览

- 拖 `w`/`h`（gauge）看形状怎么随线材变化，拖「当前第 N 圈」逐圈对照：已钩变蓝、当前圈琥珀、未钩半透明。
- 下方侧视图叠加「目标轮廓（虚线）」与「实际针数换算（实线）」，两条线的差距就是整数化代价。

## 设计原则

1. **单一真源**：文字图解、符号图解、3D 预览三条渲染路径只读同一份 IR。两边显示不一致 = 代码 bug，不是参数差异。
2. **确定性优先**：模型（AI）只负责模糊的事（想形状、分件、配色、文案），针数序列必须由求解器算。
3. **校验器先行**：先有对错判据，再谈生成。
4. **诚实暴露偏差**：整数化和约束修正的结果要显示出来，不藏。
